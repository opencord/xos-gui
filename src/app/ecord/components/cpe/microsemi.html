Customer Premises Equipment device:

Hardware: Microsemi EdgeAssure 1000 SFP-NID
Management Protocol: NETCONF/YANG
Power: 1.2 Watts
Firmware version: 1.0.0

Hardware:
  • 56.5mm SFP NID
  • 1000Base-LX Single Mode 1310nm
  • Remote firmware update capability
  • Zero Touch Provisioning using LLDP-MED & DHCP
  • in band management on both ports
  • DDM stats access via I2C and remotely via NETCONF
Traffic:
  • Up to 32 Ethernet Virtual Circuits (EVCs) can be configured
  • 0,1 & 2 VLAN (Q-in-Q) tags supported per EVC – push/pop/overwrite of the outer tag (VID,PCP,DE)
  • Tunnel, discard or process L2CP frames as per MEF 10.3
Monitoring:
  • Up to 64 Monitoring End Points (MEPs) supported per device
  • Up to 128 concurrent PM sessions each measuring loss, delay and jitter running at 100ms sampling rate
  • Uses Continuity Check Messaging (CCM) to detect connectivity faults
  • Eight-hour statistics history for up to 128 loss; delay and jitter measurements stored and persisted in non-volatile memory
Service Activation Testing:
  • ITU Y.1564 Service Activation Test on eight channels up to full line rate
  • RFC2544 line rate test
